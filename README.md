# 🐍 hwd — курс Python

Рабочее пространство для конспектов и практики по мере прохождения курса Python.

## Как устроено

- Каждый **модуль** — отдельная папка (нумерация как в курсе).
- Внутри модуля:
  - `README.md` — содержание и описание модуля
  - `reference/` — вспомогательные материалы
  - конспекты лекций (`.md`)
  - `tasks/` — задания и решения
- `reference/course-map.md` — общая карта курса для быстрого поиска.
