# 13.19. Специальные последовательности в строках

Специальные последовательности — комбинации символов, начинающиеся с `\`, которые интерпретируются по-особенному.

| Последовательность | Значение |
|--------------------|----------|
| `\n` | перенос строки |
| `\t` | табуляция |
| `\\` | обратный слеш |

```python
message = """Вот такие у нас участники:
Иван Василич\t54 года
Пётр Иваныч\t13 лет
Иннокентий\t38 годиков
"""

print(message)
# Вот такие у нас участники:
# Иван Василич    54 года
# Пётр Иваныч     13 лет
# Иннокентий      38 годиков
```

## Экранирование в путях

Обратный слеш в путях к файлам нужно экранировать:

```python
file_path = "C:\Users\alexey\file.txt"
print(file_path)
# ошибка!

file_path = "C:\\Users\\alexey\\file.txt"
print(file_path)
```

## Raw-строки

Буква `r` перед кавычкой обозначает *raw* (сырая строка) — спецпоследовательности не обрабатываются:

```python
file_path = r"C:\Users\alexey\file.txt"
print(file_path)
```

## Unicode-символы

Любой Unicode-символ можно вставить через его код:

```python
print("❤")     # ❤
print("❤")         # то же самое

print("\U0001F600") # 😀
print("😀")        # то же самое
```

- `\uXXXX` — для символов U+0000 – U+FFFF (4-значный код)
- `\UXXXXXXXX` — для символов выше U+FFFF (8-значный код)

Таблица Unicode-символов: https://symbl.cc/ru/
