# 13.10. Переменные

Переменная — это именованное место в памяти, которое хранит значение.

## Базовые переменные и вывод

```python
age = 18
name = "Алексей"
is_admin = False
print(age, name, is_admin)
```

Параметр `end=""` у `print` — задаёт символ в конце строки (по умолчанию `\n`, то есть перевод строки):

```python
print("Привет, ")
print("Андрей")
print("!")

print("Привет, ", end="")
print("Андрей", end="")
print("!")
```

## Изменение значения переменной

Значение переменной можно менять:

```python
age = 18
name = "Алексей"
is_admin = False
print(age, name, is_admin)

is_admin = True
print(age, name, is_admin)
```

## Именование переменных

Синтаксически можно называть переменные по-русски, но на практике так делать не надо:

```python
имя = "Петя"
```

Имена переменных — в нижнем регистре, в `snake_case`: слова разделяются символом подчёркивания. Пробел или дефис в имени переменной не допускаются.

## Присваивание из другой переменной

```python
name = "Алексей"
another_name = name
print(another_name)

age = 27
older_age = age * 2
print(older_age)
```

## Динамическая типизация

Python — язык с динамической типизацией: тип переменной определяется в момент присвоения значения. В разный момент времени переменная может ссылаться на разные типы данных:

```python
some_variable = "Привеееет"
some_variable = 10
some_variable = "Досвидули!"
```

## Пробелы вокруг `=`

Вокруг символа `=` всегда ставим пробелы — это улучшает читаемость. Синтаксически оба варианта равнозначны, но второй читается тяжелее:

```python
some_variable = "Досвидули!"  # хорошо
some_variable="Досвидули!"   # плохо
```

## Комментарии

Комментарий начинается с `#` и игнорируется интерпретатором:

```python
# это комментарий — он не исполняется
a = 1 + 2  # и вот этот текст тоже комментарий
print(a)   # да-да!
```

Всё, что написано вне комментария — исполняется. Произвольный текст вне `#` вызовет ошибку:

```python
a = 1 + 2  # а вот этот текст после # — это комментарий, он не исполняется
```
