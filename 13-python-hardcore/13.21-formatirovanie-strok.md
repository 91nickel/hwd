# 13.21. Форматирование строк

Конкатенация строк через `+` работает, но неудобна, неэффективна и небезопасна: в Python нельзя складывать строку с числом — код падает с ошибкой.

```python
age = 28
print("итак, тебе " + age + "лет")  # ошибка: нельзя str + int + str
```

Python предлагает три способа форматирования строк:
- Старый стиль через `%` (из C)
- Метод `.format()`
- **F-строки** — современный и предпочтительный способ

## Стиль через % (старый)

Пришёл из C. Используется редко, но встречается в старом коде.

```python
name = "Анна"
age = 30
print("Имя: %s, возраст: %s" % (name, age))
```

Спецификаторы формата:
- `%s` — строка (подойдёт и для чисел — Python приведёт автоматически)
- `%d` — целое число (строку не примет, упадёт с ошибкой)
- `%f` — число с плавающей точкой (строку не примет, упадёт с ошибкой)

```python
print("Имя: %s, возраст: %d" % (name, age))   # работает
print("Имя: %d, возраст: %d" % (name, age))   # ошибка: name — строка
```

Управление точностью:

```python
pi = 3.14159
print("Число Пи: %.2f" % pi)  # округлит до двух знаков
```

## Метод .format()

Более мощный и читаемый синтаксис, чем `%`.

```python
name = "Иван"
age = 25

# позиционные аргументы
print("Имя: {}, возраст: {}".format(name, age))

# по индексу — можно менять порядок
print("Возраст {1}, имя {0}".format(name, age))

# именованные аргументы
print("Имя: {n}, возраст: {a}".format(n=name, a=age))
```

Форматирование чисел:

```python
number = 1234.56789
print("Округлённое число: {:.2f}".format(number))
```

Когда `.format()` предпочтительнее f-строк: если шаблон хранится в переменной (например, загружается из базы данных) — f-строки тут не подходят.

```python
template = "Привет, {name}! Тебе {age} лет."
print(template.format(name="Ирина", age=22))
```

## F-строки (f-strings)

Ставим `f` перед строкой и вставляем выражения внутри `{}`. Современный и предпочтительный способ.

```python
name = "Ольга"
age = 28
print(f"Имя: {name}, возраст: {age}")
```

Внутри `{}` можно использовать любые выражения:

```python
a = 5
b = 3
print(f"{a} + {b} = {a + b}")

name = "Алексей"
print(f"Привееет, {name.upper()}!")
```

Форматирование чисел:

```python
pi = 3.1415926535
print(f"Число Пи: {pi:.3f}")  # округление до 3 знаков
```

### Выравнивание текста

```python
value = 42
print(f"Число | {value:>10}|")  # по правому краю
print(f"Число | {value:<10}|")  # по левому краю
print(f"Число | {value:^10}|")  # по центру
```

### Флаг !r — «сырое» значение

Удобно при отладке, когда важно видеть тип значения:

```python
age = 18
print(f"your age: {age}")   # 18
print(f"your age: {age!r}") # 18

age = "18"
print(f"your age: {age}")   # 18
print(f"your age: {age!r}") # '18'  — видно, что строка
```

### Экранирование фигурных скобок

```python
print(f"{{Это скобки}}")  # {Это скобки}
```

### Debug-shortcut: {переменная=}

Выводит имя переменной и её значение — очень удобно при отладке:

```python
name = "Иннокентий Смоктуновский"
print(f"{name=}")
# name='Иннокентий Смоктуновский'

age = 22
print(f"{name.upper() = }, {age = }")
# name.upper() = 'ИННОКЕНТИЙ СМОКТУНОВСКИЙ', age = 22
```
