## Версия 1 — базовая

Программа принимает размеры комнаты и параметры рулона, вычисляет нужное количество рулонов:

```python
from decimal import Decimal

# Запрашиваем размеры комнаты
room_length = Decimal(input("Введите длину комнаты (м): "))
room_width = Decimal(input("Введите ширину комнаты (м): "))
room_height = Decimal(input("Введите высоту комнаты (м): "))

# Запрашиваем параметры обоев
roll_width = Decimal(input("Введите ширину рулона обоев (м): "))
roll_length = Decimal(input("Введите длину рулона обоев (м): "))

# Общая площадь стен
walls_area = 2 * (room_length + room_width) * room_height

# Площадь одного рулона
roll_area = roll_width * roll_length

# Требуемое количество рулонов
rolls_needed = walls_area / roll_area

print("-" * 10)
print("Площадь стен:", walls_area, "м²")
print("Площадь одного рулона:", roll_area, "м²")
print("Необходимо рулонов:", rolls_needed)
```

Пример работы:

```
Введите длину комнаты (м): 1
Введите ширину комнаты (м): 2
Введите высоту комнаты (м): 3
Введите ширину рулона обоев (м): 0.6
Введите длину рулона обоев (м): 12
----------
Площадь стен: 18 м²
Площадь одного рулона: 7.2 м²
Необходимо рулонов: 2.5
```

Результат `2.5` — некруглое число. В реальности нельзя купить половину рулона, нужно округлять вверх.

## math.ceil — округление вверх

`math.ceil(x)` возвращает наименьшее целое ≥ x. Работает и с `float`, и с `Decimal`:

```python
from decimal import Decimal
import math

math.ceil(1)            # 1
math.ceil(1.0)          # 1
math.ceil(1.000001)     # 2
math.ceil(1.1)          # 2
math.ceil(1.9)          # 2
math.ceil(1.9999)       # 2

math.ceil(Decimal("1"))          # 1
math.ceil(Decimal("1.000001"))   # 2
math.ceil(Decimal("1.1"))        # 2
math.ceil(Decimal("1.9"))        # 2
math.ceil(Decimal("1.9999"))     # 2
```

## Версия 2 — с округлением

```python
from decimal import Decimal
import math

# Запрашиваем размеры комнаты
room_length = Decimal(input("Введите длину комнаты (м): "))
room_width = Decimal(input("Введите ширину комнаты (м): "))
room_height = Decimal(input("Введите высоту комнаты (м): "))

# Запрашиваем параметры обоев
roll_width = Decimal(input("Введите ширину рулона обоев (м): "))
roll_length = Decimal(input("Введите длину рулона обоев (м): "))

# Общая площадь стен
walls_area = 2 * (room_length + room_width) * room_height

# Площадь одного рулона
roll_area = roll_width * roll_length

rolls_needed = math.ceil(walls_area / roll_area)  # добавлено округление!

```

## Версия 3 — учёт окон, дверей и полос

Реальная задача сложнее: нужно вычитать площадь окон и дверей, а сами полосы клеятся строго от пола до потолка — нельзя использовать остаток рулона от предыдущей полосы.

```python
from decimal import Decimal
import math

# Запрашиваем размеры комнаты
room_length = Decimal(input("Введите длину комнаты (м): "))
room_width = Decimal(input("Введите ширину комнаты (м): "))
room_height = Decimal(input("Введите высоту комнаты (м): "))
room_windows_doors_area = Decimal(input("Введите общую площадь окон и дверей (м²): "))

# Запрашиваем параметры обоев
roll_width = Decimal(input("Введите ширину рулона обоев (м): "))
roll_length = Decimal(input("Введите длину рулона обоев (м): "))

# Общая площадь стен за минусом площади дверей и окон
walls_area = 2 * (room_length + room_width) * room_height - room_windows_doors_area

# Площадь одной полосы обоев от пола до потолка
one_strip_area = roll_width * room_height

# Требуемое количество полос
strips_needed = math.ceil(walls_area / one_strip_area)

# Сколько полос в рулоне
strips_per_roll = math.floor(roll_length / room_height)

# Количество рулонов
rolls_needed = math.ceil(strips_needed / strips_per_roll)

print("-" * 10)
print("Площадь стен:", walls_area, "м²")
print("Площадь одной полосы обоев:", one_strip_area, "м²")
print("Нужно полос:", strips_needed)
print("Полос в рулоне:", strips_per_roll)
print("Необходимо рулонов:", rolls_needed)
```

В программе пока нет обработки ошибок (нечисловой ввод, отрицательные значения и т.п.) — это тема следующих уроков.
