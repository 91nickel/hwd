# 13.17. Почему мы пишем консольные программы, ими же никто не будет пользоваться?

Консольные программы — это учебный формат. Графические интерфейсы (GUI) — тема отдельная и не нужна на старте.

Пример реальной Python-программы с GUI — **Calibre** (менеджер электронных книг). Она написана на Python и при этом имеет полноценный графический интерфейс. Python не ограничивает разработку консолью.
