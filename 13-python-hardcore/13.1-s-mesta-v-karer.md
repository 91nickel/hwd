## 1. Выделение лиц на картинке

Берём фото с YouTube, находим лица с помощью каскадного классификатора Хаара и обводим их прямоугольником.

**Библиотеки:** `opencv-python`, `Pillow`, `numpy`, `matplotlib`, `requests`

```python
!pip -q install opencv-python matplotlib requests

import cv2, requests
import numpy as np
from io import BytesIO
from PIL import Image
import matplotlib.pyplot as plt

# 1) Скачиваем фото
url = "https://i3.ytimg.com/vi/__VUu6gN_dM/maxresdefault.jpg"
img = np.array(Image.open(BytesIO(requests.get(url).content)).convert("RGB"))

# 2) Загружаем каскад
face_cascade = cv2.CascadeClassifier(
    cv2.data.haarcascades + "haarcascade_frontalface_default.xml"
)

# 3) Детекция
gray = cv2.cvtColor(img, cv2.COLOR_RGB2GRAY)
faces = face_cascade.detectMultiScale(gray, scaleFactor=1.1, minNeighbors=5)

# 4) Рисуем рамки
img_draw = img.copy()
for (x, y, w, h) in faces:
    cv2.rectangle(img_draw, (x, y), (x+w, y+h), (0, 255, 0), 3)

plt.imshow(img_draw)
plt.axis("off")
plt.show()
```

## 2. Генерация QR-кода

Декодируем зашифрованное сообщение (XOR + zlib + base64) и превращаем его в QR-код.

**Библиотеки:** `qrcode[pil]`, `base64`, `zlib`, `matplotlib`

```python
!pip -q install qrcode[pil]

import base64, zlib
from matplotlib import pyplot as plt
import qrcode

cipher_b64 = "MdXy+bYrisxUXn8UkUPIXtJdZ6VKWBrJ6xJnJfL5qiuazEReP0owksilz8KEXj9jS0mzmWx8"
key = 73

raw        = base64.b64decode(cipher_b64)
compressed = bytes(b ^ key for b in raw)   # XOR-расшифровка
message    = zlib.decompress(compressed).decode("utf-8")

img = qrcode.make(message)
plt.imshow(img, cmap="gray")
plt.axis("off")
plt.show()
```

## 3. Построение маршрута на карте

Геокодируем два адреса через Nominatim (OSM), строим маршрут через OSRM, отображаем на интерактивной карте.

**Библиотеки:** `folium`, `requests`  
**Профиль движения:** `"driving"` / `"walking"` / `"cycling"`

```python
!pip -q install folium requests

import folium, requests

start_query = "Москва, Охотный ряд, 2"
end_query   = "Москва, ВДНХ"
profile     = "driving"

def geocode(query: str):
    url    = "https://nominatim.openstreetmap.org/search"
    params = {"q": query, "format": "json", "limit": 1, "accept-language": "ru"}
    r = requests.get(url, params=params, headers={"User-Agent": "colab-student-demo"}, timeout=15)
    r.raise_for_status()
    data = r.json()
    if not data:
        raise ValueError(f"Не удалось найти координаты для: {query}")
    return float(data[0]["lat"]), float(data[0]["lon"]), data[0].get("display_name", query)

start_lat, start_lon, _ = geocode(start_query)
end_lat,   end_lon,   _ = geocode(end_query)

# Маршрут через OSRM
r = requests.get(
    f"https://router.project-osrm.org/route/v1/{profile}/{start_lon},{start_lat};{end_lon},{end_lat}",
    params={"overview": "full", "geometries": "geojson", "alternatives": "false", "steps": "false"},
    timeout=20,
)
r.raise_for_status()
route = r.json()
if route.get("code") != "Ok" or not route.get("routes"):
    raise RuntimeError("OSRM не вернул корректный маршрут.")

best         = route["routes"][0]
geom         = best["geometry"]["coordinates"]   # [lon, lat]
distance_km  = best["distance"] / 1000.0
duration_min = best["duration"] / 60.0

# Карта
m = folium.Map(location=[(start_lat+end_lat)/2, (start_lon+end_lon)/2], zoom_start=12)
folium.GeoJson(
    {"type": "Feature", "geometry": {"type": "LineString", "coordinates": geom}},
    tooltip=f"~{distance_km:.1f} км, ~{duration_min:.0f} мин",
    style_function=lambda x: {"weight": 5, "opacity": 0.9},
).add_to(m)

lats = [start_lat, end_lat] + [lat for _, lat in geom]
lons = [start_lon, end_lon] + [lon for lon, _ in geom]
m.fit_bounds([[min(lats), min(lons)], [max(lats), max(lons)]])
m
```

## 6. Генеративное искусство

Случайные прямоугольники — «Мондриан за секунды».

**Библиотека:** `matplotlib`, `random`

```python
import matplotlib.pyplot as plt
import random

fig, ax = plt.subplots(figsize=(6, 6))
for _ in range(20):
    x, y = random.random(), random.random()
    w, h = random.random() / 3, random.random() / 3
    color = random.choice(["red", "blue", "yellow", "white", "black"])
    ax.add_patch(plt.Rectangle((x, y), w, h, facecolor=color, edgecolor="black", linewidth=2))

ax.set_xlim(0, 1)
ax.set_ylim(0, 1)
ax.axis("off")
plt.show()
```

## 9. Проверка пароля на утечку

Используем k-Anonymity: на сервер уходят только первые 5 символов SHA-1-хэша — пароль не раскрывается.

```python
import hashlib, requests, getpass

pwd    = getpass.getpass("Введите пароль (не показывается): ")
sha1   = hashlib.sha1(pwd.encode()).hexdigest().upper()
prefix, suffix = sha1[:5], sha1[5:]

resp = requests.get(f"https://api.pwnedpasswords.com/range/{prefix}", timeout=15)
resp.raise_for_status()

compromised = dict(line.split(":") for line in resp.text.splitlines())
found       = compromised.get(suffix, None)

print("⚠️ Найден в утечках!" if found else "✅ В утечках не найден.")
if found:
    print("Сколько раз встречался:", int(found))
```
