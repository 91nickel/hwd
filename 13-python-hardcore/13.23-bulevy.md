# 13.23. Булевы

Булевский тип данных (`bool`) отвечает на вопросы, у которых есть только два ответа — да или нет. У типа два значения:
- `True` — истина
- `False` — ложь

Вы в целом уже работали с этим типом данных в SQL. Обрати внимание: в Python булевы значения пишутся **с заглавной буквы** — `True`, `False`. Это не строки, а специальные значения, относящиеся к типу `bool`.

```python
a = True
b = False
print(type(a), a)
print(type(b), b)
```

Тип отвечает на вопросы вроде: «Является ли число положительным?», «Равны ли две строки?», «Больше ли один объект другого?». Такие вопросы часто встречаются в программировании. Пока мы не изучили конструкции, которые разветвляют логику в зависимости от истинности значения, мы можем просто наблюдать, как Python вычисляет логические выражения и что возвращает.

## Операторы сравнения

Выражения, в которых сравниваются значения, всегда возвращают результат типа `bool`.

| Оператор | Описание | Пример | Результат |
|----------|----------|--------|-----------|
| `==` | Равно | `2 == 2` | `True` |
| `!=` | Не равно | `3 != 5` | `True` |
| `>` | Больше | `5 > 2` | `True` |
| `<` | Меньше | `1 < 0` | `False` |
| `>=` | Больше или равно | `4 >= 4` | `True` |
| `<=` | Меньше или равно | `6 <= 3` | `False` |

```python
print(10 > 5)      # True
print(3 == 4)      # False
print(7 != 7)      # False
```

## `=` и `==` — это разные вещи

Один символ равно — это оператор **присваивания**:

```python
name = "Алексей"
```

Два символа равно — это оператор **сравнения**: он проверяет, равна ли левая часть правой.

```python
name = "Алексей"
print(name == "Алексей")
print(name == "Пётр")
```

## Функции, возвращающие bool

Многие функции возвращают булевы значения. Например, проверка, входит ли строка в другую строку:

```python
message = "дратути, меня зовут Иваныч"
print("зовут" in message)
```

Можно проверять, является ли строка числом:

```python
user_age = input("Введи свой возраст числом: ")
print("тип в user_age", type(user_age), "\nuser_age.isdigit() =", user_age.isdigit())
```

## Именование булевых переменных

Переменные, в которых хранится булевское значение, часто именуют с приставкой `is_`, `can_`, `has_`. Это сразу показывает читателю, что здесь булевское значение.

```python
# является ли пользователь администратором
is_admin = False

# может ли пользователь просматривать какую-то веб-страничку
can_view_page = True

# есть ли у пользователя права на удаление какой-то записи
can_delete_record = False
```

## Преобразование в bool: функция bool()

Python умеет преобразовывать значения в `True` и `False` вызовом `bool()`.

Для чисел правила простые: `0` преобразуется в `False`, всё остальное — в `True`.

```python
print(bool(0))       # False
print(bool(123))     # True
print(bool(-5))      # True
```

Для строк: любая непустая строка — `True`, пустая — `False`.

```python
print(bool(""))         # False
print(bool("Привет"))   # True
```

Это бывает полезно при проверке: пустая ли строка, равно ли число нулю и так далее.

## Программа «Угадай число»

Загадано какое-то число, пользователь вводит число. Если угадал — печатается `True`, иначе — `False`.

```python
user_number = input().strip()
print(user_number == "42")
```

`input()` возвращает строку, поэтому нельзя сравнивать её с числом напрямую — в `print` сравниваем переменную со строкой `"42"`. Если введённая строка равна `"42"` — результатом будет `True`, иначе — `False`.

## Сравнение с двумя числами

В Python можно сравнивать число сразу с двумя другими:

```python
user_number = 10
print(3 < user_number < 100)

user_number = 100
print(3 < user_number < 100)

user_number = 100
print(3 < user_number <= 100)
```

## Таблица истинности

Таблица истинности показывает результат выполнения логических операций.

### Not — отрицание

| NOT | Истина? |
|-----|---------|
| `not False` | `True` |
| `not True` | `False` |

### Or — или

| OR | Истина? |
|----|---------|
| `True or False` | `True` |
| `True or True` | `True` |
| `False or True` | `True` |
| `False or False` | `False` |

### And — и

| AND | Истина? |
|-----|---------|
| `True and False` | `False` |
| `True and True` | `True` |
| `False and True` | `False` |
| `False and False` | `False` |

### Not Or

| NOT OR | Истина? |
|--------|---------|
| `not (True or False)` | `False` |
| `not (True or True)` | `False` |
| `not (False or True)` | `False` |
| `not (False or False)` | `True` |

### != — не равно

| `!=` | Истина? |
|------|---------|
| `1 != 0` | `True` |
| `1 != 1` | `False` |
| `0 != 1` | `True` |
| `0 != 0` | `False` |

### == — равно

| `==` | Истина? |
|------|---------|
| `1 == 0` | `False` |
| `1 == 1` | `True` |
| `0 == 1` | `False` |
| `0 == 0` | `True` |

## Как читать логические операции

`not` — это отрицание («НЕ»). `not False` — «НЕ ЛОЖЬ» — есть `True`. `not True` — отрицание правды — это `False`.

`True or False` — «правда или ложь». Если из двух суждений, соединённых «или», хотя бы одно истинно, то и общее суждение истинно. Пример: «Я Алексей» (истина) **или** «я лежу на пляже» (ложь) — общее суждение истинно, потому что я Алексей.

Если же суждения соединены «и», то для истинности общего суждения **оба** исходных должны быть истинными. «Я Алексей» (истина) **и** «я лежу на пляже» (ложь) — общее суждение ложно.

`not (True or False)` — сначала вычисляется результат в скобках: `True or False` даёт `True`. Затем отрицание `True` даёт `False`.

```python
print("not False is", not False)
print("not True is", not True)
```

Все эти вещи уже разбирались в главе о PostgreSQL — они там работают ровно так же. Обязательно убедись, что все эти операции отлично понятны — это основа программирования.
