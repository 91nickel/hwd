# 13.26. Ветвление логики, булевские операции, дебаггер

Самый простой способ разветвить логику, который есть, наверное, во всех современных ЯП — это `if` / `else`.

Простой пример. Представим, что мы пишем программу, которая сообщает пользователю, взрослый он или нет:

```python
age = 18

if age >= 18:
    print("Вы совершеннолетний!")
else:
    print("Вы несовершеннолетний!")
```

Если `age >= 18`, то есть возраст больше или равен 18, печатается сообщение, что пользователь совершеннолетний. В противном случае — что он несовершеннолетний.

**Запуск дебаггера в VS Code:** ставим точку останова на самой первой строке кода (красная точка слева от строки с кодом) и нажимаем `F5` или в меню выбираем Run → Start Debugging.

## else — опциональный

Блок `else` в конструкции `if`/`else` — опциональный. Если при невыполнении условия не нужно ничего делать, этот блок можно просто опустить:

```python
age = 15

if age >= 18:
    print("Вы совершеннолетний!")
```

Здесь просто ничего не напечатается: возраст пользователя 15, а 15 не больше или равно 18. Условие не выполнено, поэтому `print` не срабатывает. Дебаггер показывает, что в ветку с печатью программа не заходит.

## Синтаксис if

Как видите, синтаксис конструкции `if` очень простой:

```python
if условие:
    # блок кода, который выполнится, если условие истинно
```

Python проверяет булевское значение условия. Если оно `True` — выполняется блок. Если `False` — блок пропускается.

Например:

```python
temperature = 30

if temperature > 25:
    print("Жарко!")
```

Если `temperature > 25`, то `print("Жарко!")` выполняется. Иначе — программа идёт дальше, ничего не делая.

## Отступы

Обрати особое внимание на отступы. В Python блоки кода определяются отступами — обычно 4 пробела. Без них программа не поймёт, где заканчивается условие.

Те, кто пришёл в Python с других языков, часто недоумевают, почему отступы являются частью синтаксиса. Да, в Python отступы — действительно часть синтаксиса языка. Более того, если попробовать проимпортировать фигурные скобки:

```python
from __future__ import braces
```

то увидим сообщение — *not a chance*, без шансов. Импортирование — это подключение к своей программе других пакетов и модулей (своих, из стандартной библиотеки или сторонних). В Python можно иногда импортировать из «будущего» какие-то будущие возможности языка. И разработчики сделали ради прикола импортирование фигурных скобок, которое возвращает ошибку: нет, без шансов, фигурных скобок в Python не будет. Такая пасхалка.

## Несколько условий: elif

А что, если у нас не просто два варианта логики, а несколько?

Например, программа, которая оценивает температуру и выводит не просто «жарко», а «жарко / тепло / прохладненько»:

```python
temperature = 15

if temperature > 25:
    print("Жарко!")
elif temperature > 15:
    print("Тепло.")
else:
    print("Прохладненько!")
```

- Если температура больше 25 — выводим «Жарко!»
- Если первое условие не сработало, проверяется `elif temperature > 15`
- Если и оно ложно, срабатывает `else`

Важно: как только срабатывает одно из условий, остальные игнорируются, даже если они тоже могли бы сработать. То есть порядок ветвей — важен. Ветвей может быть сколь угодно много.

## Логические операторы

Иногда нужно проверить несколько условий одновременно. Например, что пользователь ввёл пароль и согласился с условиями. Это делается с помощью логических операторов.

**`and`** — логическое «и». Срабатывает, только если оба условия истинны:

```python
age = 20
has_ticket = True

if age >= 18 and has_ticket:
    print("Добро пожаловать на концерт!")
else:
    print("Извините, вход запрещён.")
```

**`or`** — логическое «или». Срабатывает, если хотя бы одно условие истинно:

```python
is_admin = False
is_moderator = True

if is_admin or is_moderator:
    print("У вас есть доступ к панели управления.")
```

**`not`** — логическое «не», инвертирует значение:

```python
is_banned = False

if not is_banned:
    print("Пользователь может писать сообщения.")
```

`not False` превращается в `True`, и блок выполняется.

## Что считается ложным

В условиях можно писать не только булевские значения. Python сам преобразует выражения в логические. Вот что считается ложным из знакомых нам типов:

- `False`
- `None`
- `0`, `0.0`
- Пустые строки: `""`
- Пустые списки, множества и словари: `[]`, `{}`, `set()` (поговорим о них позже)

Всё остальное — истинно. То есть число `0` преобразуется в `False`, а `0.1` — в `True`, так же как `1`, `2`, `10` и `286`.

Пример — проверка, ввёл ли пользователь имя:

```python
name = input().strip()

if name:
    print("Привет,", name)
else:
    print("Вы не ввели имя.")
```

При вводе пустой строки та самая `""` считается ложной, поэтому срабатывает ветка `else`.

## Проверка пароля

```python
password = input("Введите пароль: ")

if password == "1234":
    print("Доступ разрешён.")
else:
    print("Неверный пароль.")
```

Пользователь вводит пароль, программа сравнивает его с правильным значением и пускает или не пускает. В реальной системе в базе хранится хэш пароля, и этот хэш сравнивается с хэшем от введённого пользователем пароля. Но принцип ровно тот же.

## Хитрый калькулятор доставки

```python
total = 1200
is_member = True

if total > 1000 or is_member:
    delivery_price = 0
else:
    delivery_price = 300

print("Доставка стоит {delivery_price} руб.")
```

Если сумма больше 1000 или пользователь — участник клуба, доставка бесплатна, в противном случае она стоит 300 руб.

## Чётные и нечётные числа

```python
number = 7

if number % 2 == 0:
    print("Чётное число.")
else:
    print("Нечётное число.")
```

Здесь используется остаток от деления `%`. Если число делится на 2 без остатка — оно чётное.

## Частые ошибки новичков

**1. Забытый отступ** после `if`, `else`, `elif`:

```python
if x > 0:
print("Положительное")  # Ошибка! Нужно добавить отступ.
```

**2. Сравнение `=` вместо `==`:**

```python
if x = 5:  # Ошибка! Один знак равенства — это присваивание.
```

Нужно писать `==` для сравнения.

**3. Сложные условия без скобок.** Хотя Python понимает порядок операций, иногда лучше использовать скобки для ясности:

```python
if (x > 0 and y > 0) or is_admin:
    print("Доступ разрешён.")
```
