# 13.24. None

Так же, как в SQL есть значение `null`, в Python есть значение `None`.

`None` — это специальное значение, которое означает «ничего», «пусто» или «значение отсутствует». Это **не ноль**, **не пустая строка** и **не `False`**. Это отдельное значение, у которого есть своё предназначение.

Когда вы пишете:

```python
user_address = None
```

это означает: переменная `user_address` существует, но пока у неё нет конкретного значения. Возможно, это значение будет позднее задано, а возможно, и нет.

## Тип NoneType

`None` относится к специальному типу `NoneType`, в чём можно убедиться:

```python
print(type(None))
```

При этом в Python существует только **один объект** `None`. Объектов типа `str` или `int` может быть много, а объект типа `NoneType` только один — это `None`.

## None и булевы значения

При преобразовании к булевскому значению `None` всегда возвращает `False`:

```python
print(
    bool(None)
)
# False
```
