## Примеры

### Версия интерпретатора

```python
import sys
print(f"Используемая тут версия Python {sys.version}")
```

### Установка Python через uv

```bash
# показать все возможные версии Python, которые можно установить
uv python list

# установить конкретную версию
uv python install 3.13.3
uv python list
# видно пути до установленных версий питона
```

### Hello, world

```python
print("hello, world")
```

### Строка, склеенная 100 раз

```python
print("hello, world" * 100)
```

### Дефис 20 раз

```python
print("-" * 20)
```

### Создание и запуск файла

```bash
mkdir -p ~/code/learn && cd $_
nano hello.py
```

```python
print("hello, world!")
```

```bash
# путь до интерпретатора — смотри uv python list
/home/sterx/.local/share/uv/python/cpython-3.13.3-linux-x86_64-gnu/bin/python3.13 hello.py

# или через uv
uv run hello.py
```
