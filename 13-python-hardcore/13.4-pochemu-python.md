# 13.4 — Почему Python?

## Популярность

Python стабильно занимает первые позиции в рейтинге языков программирования
[TIOBE Index](https://www.tiobe.com/tiobe-index/).

## Применение за пределами IT

Python используют специалисты из самых разных областей — не только программисты.
Пример: врач УЗИ написал программу для автоматической подготовки медицинских протоколов.

→ [УЗИарт: как врач УЗИ создал себе программу для автоматической подготовки медицинских протоколов](https://habr.com/ru/articles/924450/) (Habr)

## Почему Python, а не другой язык?

Низкий порог входа, читаемый синтаксис, огромная экосистема библиотек.
Именно поэтому его выбирают учёные, врачи, аналитики — люди, которым нужно решить задачу, а не стать программистами.

## Название

Python назван не в честь змеи, а в честь британского комедийного шоу
[Monty Python's Flying Circus](https://www.google.com/search?q=Monty+Python).
Гвидо ван Россум читал сценарии шоу во время работы над языком.
