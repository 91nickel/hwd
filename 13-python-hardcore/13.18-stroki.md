# 13.18. Строки

## Виды кавычек

Строки — это текст. Задать строку можно четырьмя способами:

```python
name = "Алексей"
name = 'Алексей'
name = """Алексей"""
name = '''Алексей'''
```

Тройные кавычки (`"""` и `'''`) — для многострочных текстов. Одинарные и двойные (`"` и `'`) — для однострочных.

## Кавычки внутри строки

Так не работает — строка ограничена двойными кавычками, и они же встречаются внутри:

```python
# ошибка SyntaxError
some_string = "Привет, "ромашки"!"

# тоже ошибка SyntaxError
some_string = 'Привет, 'ромашки'!'
```

Решения — чередовать типы кавычек или экранировать:

```python
some_string = "Привет, \"ромашки\"!"
print(some_string)

some_string = 'Привет, "ромашки"!'
print(some_string)

some_string = 'Привет, \'ромашки\'!'
print(some_string)

some_string = "Привет, 'ромашки'!"
print(some_string)
```

Одинарные и двойные кавычки существуют именно для того, чтобы не приходилось экранировать кавычки внутри строки.

## Многострочные строки

Обычные кавычки не принимают перенос строки внутри — это ошибка:

```python
# SyntaxError
greetings = "Ну, здравствуй, дружочек!

Как твои делища?

Как поживаешь?
"
```

Для многострочных строк — тройные кавычки:

```python
greetings = """Ну, здравствуй, дружочек!

Как твои делища?
Как поживаешь?
"""
print(greetings)

greetings = '''Ну, здравствуй, дружочек!

Как твои делища?

Как поживаешь?
'''
print(greetings)
```

Можно и обычными кавычками — через `\n`:

```python
greetings = "Ну, здравствуй, дружочек!\n\nКак твои делища?\n\nКак поживаешь?"
print(greetings)
```

## Перенос длинной строки в коде

Обратный слеш `\` в конце строки говорит интерпретатору, что инструкция продолжается на следующей строке:

```python
greetings = "Ну, здравствуй, дружочек!\n\n"\
    "Как твои делища?\n\n"\
    "Как поживаешь?"
print(greetings)
```

Или обернуть в скобки — тогда `\` не нужен, всё внутри скобок считается одной инструкцией:

```python
greetings = ("Ну, здравствуй, дружочек!\n\n"
    "Как твои делища?\n\n"
    "Как поживаешь?"
)
print(greetings)

# синтаксически можно и так (на практике так писать незачем)
print(2
      +
      3)
```

## Как играться с кодом

Поиграться с кодом — значит изменить примеры, посмотреть что получится, намеренно сломать и починить. Например, исследуем строки:

```python
# в файле пишем и запускаем каждый раз

address = "Москва          # ошибка — незакрытая строка
address = "Москва"
address = 'Москва'
address = 'Москва,         # ошибка — незакрытая строка
address = 'Москва,'        # ошибка — 'Москва,' потом ул. Ленина, 2' — лишняя кавычка
ул. Ленина, 2'
address = '''Москва,
ул. Ленина, 2'''           # работает
address = '''Москва,\n
ул. Ленина, 2'''           # \n + реальный перенос = два переноса
address = '''Москва,\n\n\nул. Ленина, 2'''  # три переноса через \n
address = 'Москва,\n\n\nул. Ленина, 2'     # то же самое
address = "Москва,\n\n\nул. Ленина, 2"     # то же самое
print(address)
```

## Сложение строк

Строки складываются оператором `+`:

```python
name = "Алексей"
greetings = "Привет"

message = greetings + ", " + name + "!"
print(message)
```

Складывать строку с числом через `+` нельзя — Python не умеет их смешивать напрямую. Как вставлять числа в строки — отдельная тема.
