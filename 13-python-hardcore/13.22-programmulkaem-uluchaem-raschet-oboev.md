## Срез с отрицательным шагом — переворот строки

Срез `text[::-1]` — это полный срез строки: начальный и конечный индексы не заданы (значит, берётся вся строка), а шаг `-1` разворачивает её в противоположном порядке.

```python
text = input()
print(text[::-1])
```

## Перемножение цифр трёхзначного числа

Пользователь вводит трёхзначное число, программа перемножает его цифры и выводит результат.

```python
text = input()
first_number = int(text[0])
second_number = int(text[1])
third_number = int(text[2])

print(first_number * second_number * third_number)
```

Работает, но снова без обработки ошибок — а это плохо (научимся обрабатывать их позже).

Тот же код можно написать короче, если уже знать чуть больше Python. Вариант с циклом не ограничен только трёхзначными числами и не содержит структурного дублирования. О цикле `for` поговорим дальше в этой главе:

```python
text = input()
result = 1
for number in text:
    result *= int(number)
print(result)
```

## Улучшаем расчёт обоев: ввод с запятой

В программе из урока 13.16 параметры комнаты могут быть нецелочисленными, но принимаются только с точкой: чтобы ввести полтора метра, нужна `1.5`, а `1,5` — уже не сработает. Сделаем, чтобы можно было вводить и с запятой, и с точкой.

Идея простая: заменить все запятые на точки в тех данных, что вводит пользователь. Если запятых нет — ничего не меняется и всё работает.

```python
from decimal import Decimal
import math


# Запрашиваем размеры комнаты
room_length = Decimal(input("Введите длину комнаты (м): ").replace(",", "."))
room_width = Decimal(input("Введите ширину комнаты (м): ").replace(",", "."))
room_height = Decimal(input("Введите высоту комнаты (м): ").replace(",", "."))
room_windows_doors_area = Decimal(input("Введите общую площадь окон и дверей (м²): ").replace(",", "."))

# Запрашиваем параметры обоев
roll_width = Decimal(input("Введите ширину рулона обоев (м): ").replace(",", "."))
roll_length = Decimal(input("Введите длину рулона обоев (м): ").replace(",", "."))

...
```

Теперь можно вводить нецелочисленные значения не только с точкой, но и с запятой. Программа стала удобнее.

## Обрезаем пробелы

Пробелы мы тут не обрезаем, а стоит. Если кто-то поставил пробел или символ табуляции в начале или в конце строки, их можно просто обрезать — они погоды не делают — программа станет надёжнее:

```python
from decimal import Decimal
import math


# Запрашиваем размеры комнаты
room_length = Decimal(input("Введите длину комнаты (м): ").replace(",", ".").strip())
room_width = Decimal(input("Введите ширину комнаты (м): ").replace(",", ".").strip())
room_height = Decimal(input("Введите высоту комнаты (м): ").replace(",", ".").strip())
room_windows_doors_area = Decimal(input("Введите общую площадь окон и дверей (м²): ").replace(",", ".").strip())

# Запрашиваем параметры обоев
roll_width = Decimal(input("Введите ширину рулона обоев (м): ").replace(",", ".").strip())
roll_length = Decimal(input("Введите длину рулона обоев (м): ").replace(",", ".").strip())

...
```

В блоке запроса данных от пользователя мы много раз вызываем `input`, `Decimal`, `replace`, `strip` — это конкретное дублирование кода, его быть не должно. Когда изучим функции, покажи, как от такого избавляться.

## Вывод результатов через f-строку

Вывод результатов тоже сделаем с помощью f-строк — одним вызовом `print`:

```python
print(f"""
{"-" * 10}
Площадь стен: {walls_area} м²
Площадь одной полосы обоев: {one_strip_area} м²
Нужно полос: {strips_needed}
Полос в рулоне: {strips_per_roll}
Необходимо рулонов: {rolls_needed}
""".strip())
```
