# 13.11. Ввод данных пользователем

Переменные с захардкоженными значениями почти бесполезны — с тем же успехом можно было написать строку напрямую:

```python
name = "Алексей"
print(name)
# то же самое, что просто:
print("Алексей")
```

Чаще всего данные в переменных не зашиты в программе, а поступают извне: задаются пользователем, считываются из базы данных, из файла и т.д. На этапе написания программы мы не знаем, что именно окажется в переменной.

## Ввод через input()

`input()` выводит подсказку и ждёт, пока пользователь введёт строку и нажмёт Enter:

```python
name = input("Как тебя зовут, дружище? ")
print("уоооо, привееееет, " + name + "!")
```

Можно сохранить результат конкатенации в отдельную переменную:

```python
name = input("Как тебя зовут, дружище? ")
greetings = "уоооо, привееееет, " + name + "!"
print(greetings)
```

## Ввод через аргументы командной строки

`sys.argv` — список аргументов, переданных программе при запуске. `sys.argv[0]` — имя файла, `sys.argv[1]` — первый аргумент:

```python
import sys
name = sys.argv[1]
print("ну, привет, " + name + "!")
```

Запуск:

```bash
uv run hello.py Алексей
```
