# 13.12. Числовые типы данных, арифметика

## int и float

`int` — целое число, `float` — нецелое. Тип определяется автоматически:

```python
salary = 180000
increased_salary = 1.3 * salary
print("Если ЗП увеличится на 30%, она составит: ", increased_salary)
```

Длинные числа можно записывать с символом подчёркивания для читаемости:

```python
salary = 180_000    # рекомендуется: отделять тысячи
salary = 1_8_0_0_00  # синтаксически работает, но так делать не стоит
```

## type() и приведение типов

`type()` возвращает тип значения. `int()` и `float()` — функции приведения:

```python
print(type(salary))           # <class 'int'>
print(type(increased_salary)) # <class 'float'>

print(int(1.5))   # 1 — отбрасывает дробную часть
print(float(20))  # 20.0
```

## Операторы

**Остаток от деления `%`** — не процент, а именно остаток:

```python
some_number = 12
print(some_number % 2)  # 0 — чётное
some_number = 11
print(some_number % 2)  # 1 — нечётное
```

**Возведение в степень `**`:**

```python
print(2 ** 3)  # 8
```

**Целочисленное деление `//`** — результат без дробной части:

```python
print(10 // 2)   # 5
print(10 // 3)   # 3
print(10 // 4)   # 2
print(10 // 5)   # 2
print(10 // 6)   # 1
print(10 // 11)  # 0
```

## Округление

```python
print(round(2.1))      # 2
print(round(2.49))     # 2
print(round(2.50001))  # 3
print(round(2.9))      # 3
```

## Инкремент и декремент

Синтаксический сахар для частой операции изменения числа:

```python
index = 123

index += 1  # то же что index = index + 1
index -= 1  # то же что index = index - 1

# аналогично для * и /
index *= 2
index /= 2  # будет 100.0 — результат деления целых в Python всегда float
```

Комплексные числа в Python тоже есть, но в веб-разработке почти не используются.
