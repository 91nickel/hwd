# Задание 13.21.7 — Переменные для выражения a + b

Код, идущий сразу после твоего кода:

```python
print(f"{a + b = }")
```

Напиши свой код, чтобы вся программа работала вот так:

```
$ python3 main.py 10 20
a + b = 30

$ python3 main.py 50 6
a + b = 56
```

Обрати внимание — не повторяй код с `print`, приведённый выше.

## Ответ

```python
import sys

a = int(sys.argv[1])
b = int(sys.argv[2])
```
