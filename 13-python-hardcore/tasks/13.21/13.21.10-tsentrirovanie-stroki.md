# Задание 13.21.10 — Центрирование строки

Напиши программулечку, которая принимает на вход три параметра — начальную строку, число и один символ:

```
$ python3 main.py "привет" 20 "="
=======привет=======

$ python3 main.py "привет" 20 "."
.......привет.......

$ python3 main.py "XXX" 2 "."
XXX

$ python3 main.py "XXX" 3 "."
XXX

$ python3 main.py "XXX" 4 "."
XXX.

$ python3 main.py "XXX" 5 "."
.XXX.

$ python3 main.py "XXX" 6 "."
.XXX..

$ python3 main.py "XXXX" 4 "."
XXXX

$ python3 main.py "XXXX" 5 "."
.XXXX

$ python3 main.py "XXXX" 6 "."
.XXXX.

$ python3 main.py "XXXX" 7 "."
..XXXX.
```

## Ответ

```python
import math
import sys

word = sys.argv[1].strip()
length = int(sys.argv[2])
sep = sys.argv[3].strip()

if length <= len(word):
    output = word
else:
    if len(word) % 2 == 0:
        left_len = math.ceil((length - len(word)) / 2)
        right_len = length - len(word) - left_len
    else:
        right_len = math.ceil((length - len(word)) / 2)
        left_len = length - len(word) - right_len

    output = sep * left_len + word + sep * right_len

print(output)
```

### Сообщение от преподавателя

У строк есть встроенная функция `center`:

```python
import sys

print(sys.argv[1].center(int(sys.argv[2]), sys.argv[3]))
```

Для продакшн-кода, конечно, стоит побить по переменным, чтобы было понятно, что тут происходит:

```python
import sys

input_string = sys.argv[1]
required_length = int(sys.argv[2])
fill_char = sys.argv[3]
centered = input_string.center(required_length, fill_char)
print(centered)
```
