## Задание 13.21.8

Напиши программулечку, которая работает вот так:

```
$ python3 main.py "x=10,y=20"
x = 10; y = 20

$ python3 main.py "tmp=23231,another=5414"
tmp = 23231; another = 5414

$ python3 main.py "tmp=-23231,another=5414"
tmp = -23231; another = 5414
```

Известно, что во входной строке может быть строго два знака `=`.

Используй f-строку. Не используй тут списки, кортежи, множества, словари, регулярные выражения (мы о них будем говорить дальше в этой главе курса).

## Ответ

```python
import sys

arg = sys.argv[1]

first_eq_position = arg.find("=")
second_eq_position = arg.rfind("=")
comma_position = arg.find(",")

first_key = arg[:first_eq_position]
second_key = arg[comma_position + 1:second_eq_position]

first_value = arg[first_eq_position + 1:comma_position]
second_value = arg[second_eq_position + 1:]

print(f"{first_key} = {first_value}; {second_key} = {second_value}")
```

Да, тут пришлось очень внимательно в математику, ясное дело :) Во все эти `+ 1` и подобное, внимательно с индексами.

Если бы можно было пользоваться списками (о которых дальше будем говорить), то было бы легко:

```python
import sys

arg = sys.argv[1]

first_param, second_param = arg.split(",")
first_key, first_value = first_param.split("=")
second_key, second_value = second_param.split("=")

print(f"{first_key} = {first_value}; {second_key} = {second_value}")
```

А если бы можно было использовать регулярные выражения (тоже дальше о них поговорим):

```python
import re
import sys

arg = sys.argv[1]
pattern = r"^([^=]+)=(-?\d+),([^=]+)=(-?\d+)$"
match = re.fullmatch(pattern, arg)
first_key, first_value, second_key, second_value = match.groups()
print(f"{first_key} = {first_value}; {second_key} = {second_value}")
```

## Задание 13.21.10

Напиши программулечку, которая принимает на вход три параметра — начальную строку, число и один символ:

```
$ python3 main.py "привет" 20 "="
=======привет=======

$ python3 main.py "привет" 20 "."
.......привет.......

$ python3 main.py "XXX" 2 "."
XXX

$ python3 main.py "XXX" 3 "."
XXX

$ python3 main.py "XXX" 4 "."
XXX.

$ python3 main.py "XXX" 5 "."
.XXX.

$ python3 main.py "XXX" 6 "."
.XXX..

$ python3 main.py "XXXX" 4 "."
XXXX

$ python3 main.py "XXXX" 5 "."
.XXXX

$ python3 main.py "XXXX" 6 "."
.XXXX.

$ python3 main.py "XXXX" 7 "."
..XXXX.
```

## Ответ

```python
import math
import sys

word = sys.argv[1].strip()
length = int(sys.argv[2])
sep = sys.argv[3].strip()

if length <= len(word):
    output = word
else:
    if len(word) % 2 == 0:
        left_len = math.ceil((length - len(word)) / 2)
        right_len = length - len(word) - left_len
    else:
        right_len = math.ceil((length - len(word)) / 2)
        left_len = length - len(word) - right_len

    output = sep * left_len + word + sep * right_len

print(output)
```

## Задание 13.21.12

Напиши программулечку, которая принимает на вход количество секунд, и форматирует их в минуты, секунды и сотые доли секунды:

```
$ python3 main.py 125.6789
02:05.68

$ python3 main.py 11.2316
00:11.23

$ python3 main.py 386.2356
06:26.24

$ python3 main.py 9386.2356
156:26.24

$ python3 main.py 0
00:00.00
```

Минуты, секунды и сотые — с ведущими нулями.

Используй f-строку. Не используй тут списки, кортежи, множества, словари, регулярные выражения (мы о них будем говорить дальше в этой главе курса).

## Ответ

```python
import math
import sys
from decimal import ROUND_HALF_UP, Decimal

totalSecs = Decimal(sys.argv[1])

mins = totalSecs // 60
secs = math.floor(totalSecs % 60)
mSecs = (totalSecs % 1 * 100).quantize(Decimal('1'), rounding=ROUND_HALF_UP)

if len(str(mins)) < 2:
    mins = f"0{mins}"

if len(str(secs)) < 2:
    secs = f"0{secs}"

if len(str(mSecs)) < 2:
    mSecs = f"0{mSecs}"

print(f"{mins}:{secs}.{mSecs}")
```
