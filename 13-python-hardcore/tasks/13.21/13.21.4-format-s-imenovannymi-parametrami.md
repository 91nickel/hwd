# Задание 13.21.4 — format с именованными параметрами

Код, предшествующий твоему:

```python
import sys

message_template = """Здравствуйте, {name}!

Вынуждены Вам сообщить, что Вы большой молодец. Да. Так уж вышло.

До свидания, {name}!"""
user_name = sys.argv[1]
```

Напиши одну строку, чтобы вся программа работала вот так:

```
$ python3 main.py "Пётр Иванович"
Здравствуйте, Пётр Иванович!

Вынуждены Вам сообщить, что Вы большой молодец. Да. Так уж вышло.

До свидания, Пётр Иванович!

$ python3 main.py "Санёк"
Здравствуйте, Санёк!

Вынуждены Вам сообщить, что Вы большой молодец. Да. Так уж вышло.

До свидания, Санёк!
```

Обрати внимание — задание `message_template` и `user_name` не повторяй. Это код, который есть где-то выше твоего кода, то есть у тебя в твоём коде уже есть эти переменные, просто используй их.

## Ответ

```python
print(message_template.format(name=user_name))
```
