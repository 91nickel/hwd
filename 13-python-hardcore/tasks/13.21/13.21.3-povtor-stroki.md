# Задание 13.21.3 — Повтор строки

Напиши программулечку, которая принимает на вход строку и положительное целое число и печатает строку, повторённую указанное количество раз:

```
$ python3 main.py "кто здесь?" 2
кто здесь?
кто здесь?

$ python3 main.py "что происходит?!" 4
что происходит?!
что происходит?!
что происходит?!
что происходит?!
```

## Ответ

```python
import sys

print((f"{sys.argv[1].strip()}\n" * int(sys.argv[2])).strip())
```
