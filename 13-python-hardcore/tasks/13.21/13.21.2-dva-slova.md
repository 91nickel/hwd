# Задание 13.21.2 — Два слова

Не используя сложение строк, напиши программулечку, которая принимает на вход два произвольных слова, и выводит их вот так:

```
$ python3 main.py смелость храбрость
первое слово: смелость
второе слово: храбрость
```

Используй `print` один раз и не используй сложение строк.

## Ответ

```python
import sys

print(f"первое слово: {sys.argv[1].strip()}\nвторое слово: {sys.argv[2].strip()}")
```
