# Задание 13.21.9 — Фамилия и инициал

Напиши программулечку, которая работает вот так:

```
$ python3 main.py "иван петров"
Петров И.

$ python3 main.py "алексей Мусечкин"
Мусечкин А.

$ python3 main.py "василий смирнов"
Смирнов В.

$ python3 main.py "   василий   смирнов  "
Смирнов В.
```

Известно, что и имя, и фамилия строго состоят из одного слова и разделены одним или несколькими пробелами.

Используй f-строку. Не используй тут списки, кортежи, множества, словари, регулярные выражения (мы о них будем говорить дальше в этой главе курса).

## Ответ

```python
import sys

fullname = sys.argv[1].strip()

first_space_pos = fullname.find(' ')

name = fullname[:first_space_pos].capitalize()
last_name = fullname[first_space_pos + 1:].strip().capitalize()

print(f"{last_name} {name[0]}.")
```
