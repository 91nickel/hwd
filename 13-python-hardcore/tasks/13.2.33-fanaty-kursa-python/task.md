# Задание 13.2.33 — Фанаты курса обожают Python

Все фанаты нашего курса обожают язык программирования Python.

Используя только эту информацию, выбери правильное суждение из приведённых ниже и поясни, почему именно оно — правильное:

1. не бывает фанатов нашего курса, которые не любят Python
2. все, кто любят Python, являются фанатами нашего курса
3. не бывает фанатов нашего курса, которые любят Python

---

**Чат с ИИ**

**Студент:** Верен вариант 1, так как «Все фанаты нашего курса обожают язык программирования Python».
Вариант 2 содержит ошибку.
Вариант 3 прямо противоречит условию.

**Наставник:** Формально ты выбрал тот вариант, который ближе всего к исходной фразе, но объяснение сейчас слишком общее.

Проверь точнее:
1) Исходная фраза говорит: «Все фанаты курса обожают Python».
2) Вариант 1 говорит: «не бывает фанатов курса, которые не любят Python».

Это одно и то же по смыслу или есть разница? Попробуй придумать конкретный пример с людьми:
– человек А — фанат курса и любит Python;
– человек Б — фанат курса и не любит Python.

Какой из этих людей возможен по исходному условию, и как это связано с формулировкой варианта 1?

**Студент:** Не бывает фанатов нашего курса, которые не любят Python, так как «Все фанаты нашего курса обожают язык программирования Python».
