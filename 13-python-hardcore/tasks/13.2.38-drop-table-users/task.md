# Задание 13.2.38 — DROP TABLE users

Если выполнить команду DROP TABLE users, таблица с данными пользователей (users) сразу же исчезнет. Таблица users на месте. Сейчас я выполню DROP TABLE users.

Используя только эту информацию, выбери правильное суждение из приведённых ниже и поясни, почему именно оно — правильное:

1. не надо выполнять этот запрос
2. таблица users исчезнет
3. таблица users не исчезнет

---

**Чат с ИИ**

**Студент:** Таблица users исчезнет, так как «Сейчас я выполню DROP TABLE users», а «если выполнить команду DROP TABLE users, таблица с данными пользователей (users) сразу же исчезнет».

**Наставник:** Сейчас у тебя есть важная логическая дырка. В условии сказано только: если выполнить команду, то таблица исчезнет. И отдельно сказано: «Сейчас я выполню DROP TABLE users».

Вопрос: из того, что кто-то заявил, что сейчас выполнит команду, следует ли строго, что команда точно будет выполнена? Попробуй переформулировать своё объяснение, чётко разделив:
1) условие «если команда выполнена, то таблица исчезает»;
2) утверждение «я собираюсь выполнить команду».

**Студент:** В условии не говорится, что команда по каким-то причинам может быть не выполнена. Предполагаю, что подразумевается, что она всё же будет выполнена.

**Наставник:** Нет, так рассуждать в этой задаче некорректно. Нельзя «подразумевается» — нужно опираться только на то, что явно сказано.

Сравни два варианта:
1) «Команда выполнена».
2) «Сейчас я выполню команду».

Это одно и то же или нет? Можно ли из второго сделать вывод, что первое уже истинно? Ответ сформулируй в одном предложении: какой вариант из трёх ты выбираешь и почему, опираясь только на явный текст.

**Студент:** Ну раз такое дело, и мы говорим про момент вот прямо сейчас, когда я только собираюсь выполнить команду, тогда таблица users не исчезнет, так как я лишь только заявил о намерении, а не выполнил команду.
