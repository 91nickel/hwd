# Задание 13.2.17 — Иннокентий боится JS и CSS

Бэкендер Иннокентий страстно боится как JavaScript, так и CSS.

Используя только эту информацию, выбери правильное суждение из приведённых ниже и поясни, почему именно оно — правильное:

1. Иннокентий не боится CSS
2. Иннокентий боится JavaScript
3. Иннокентий боится JavaScript больше, чем CSS, но и CSS боится тоже

**Пояснения терминологии:**
- бэкендер — разработчик серверной части веб-системы
- JavaScript — язык программирования для разработки фронтенд-логики, работающей в браузере
- CSS — язык для описания внешнего вида веб-страниц
