# Задание 13.2.24 — Pet-проект: фронтенд или бэкенд

Известно, что любой учебный pet-проект обязательно или с фронтендом, или с бэкендом, или и с тем и другим сразу.

Используя только эту информацию, выбери правильное суждение и поясни, почему именно оно — правильное:

1. учебный pet-проект не может быть без бэкенда
2. учебный pet-проект не может быть одновременно без фронтенда и без бэкенда
3. учебный pet-проект не может быть с фронтендом и без бэкенда

## Чат с ИИ

**Студент:** Учебный pet-проект не может быть одновременно без фронтенда и без бэкенда, так как любой pet-проект обязательно или с фронтендом, или с бэкендом, или и с тем и другим сразу.

Учебный pet-проект может быть без бэкенда (только фронтенд).
Учебный pet-проект может быть с фронтендом и без бэкенда.

**Наставник:** Чудненько. В каком из трёх допустимых случаев (только фронтенд / только бэкенд / оба) проект будет «одновременно без фронтенда и без бэкенда»? Есть ли вообще такой вариант?

**Студент:** Не может быть проект и без фронтенда, и без бэкенда одновременно.

## Ответ

Вариант 2. Условие гарантирует наличие хотя бы одного из двух, поэтому проект не может быть одновременно без фронтенда и без бэкенда. Варианты 1 и 3 ошибочны — проект может быть только с фронтендом.
