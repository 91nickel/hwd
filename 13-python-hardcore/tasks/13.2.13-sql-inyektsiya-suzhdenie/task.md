# Задание 13.2.13 — SQL-инъекция: суждение

Если бармалеи нашли в системе SQL-инъекцию, то они мгновенно воруют данные из базы данных этой системы.

Используя только эту информацию, выбери правильное суждение из приведённых ниже и поясни, почему именно оно — правильное:

1. если бармалеи своровали данные из базы данных системы, то они нашли в системе SQL-инъекцию
2. если бармалеи не нашли в системе SQL-инъекцию, то они не своровали данные из её базы данных
3. если данные из базы данных системы бармалеями не сворованы, то бармалеи не нашли в системе SQL-инъекцию

**Пояснения терминологии:**
SQL-инъекция — уязвимость, позволяющая злоумышленникам выполнять произвольные запросы к базе данных (БД). Эта уязвимость может приводить к краже данных из БД, к удалению данных из БД, а в некоторых случаях и к получению доступа ко всему серверу с БД.

---

**Чат с ИИ**

**Студент:** Вариант 3: если данные из базы данных системы бармалеями не сворованы, то бармалеи не нашли в системе SQL-инъекцию.
Если мы однозначно утверждаем, что обнаружение инъекции = кража данных, значит в случае если данные не украли, совершенно точно инъекция не обнаружена.

Первый вариант неверен так как бармалеи могли получить доступ любым другим путем. Условие этого не запрещает.
Второй вариант не верен по той же причине: могли своровать как угодно по-другому.
