# Задание 13.2.17 — Иннокентий боится JS и CSS

Бэкендер Иннокентий страстно боится как JavaScript, так и CSS.

Используя только эту информацию, выбери правильное суждение и поясни, почему именно оно — правильное:

1. Иннокентий не боится CSS
2. Иннокентий боится JavaScript
3. Иннокентий боится JavaScript больше, чем CSS, но и CSS боится тоже

## Ответ

Вариант 2. Условие прямо говорит, что Иннокентий боится и JavaScript, и CSS — значит «боится JavaScript» — прямое следствие.

Вариант 1 прямо противоречит условию.
Вариант 3 вводит сравнение, которого в условии нет.
