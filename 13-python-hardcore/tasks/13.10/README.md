## Задание 13.10.1


## Задание 13.10.2

Напиши код, который выведет строку «дратути, мир!» и использует для этого два вызова функции print.

## Ответ

```python
print('дратути, мир', end='')
print('!')
```

## Задание 13.10.3

Напиши код, который выведет строку «дратути, мир!» и использует для этого пять вызовов функции print.

## Ответ

```python

print(', ', end='')
print('м', end='')
print('ир', end='')
print('!')
```

## Задание 13.10.5

Напиши код, который напечатает сначала строку «дратути, мир!» с переносом строки, а затем значение переменной `some_magic`. То есть, если значение переменной `some_magic` равно `216`, то результат должен быть таким:

```
дратути, мир!
216
```

Создавать переменную не нужно — будем считать, что она создана выше в коде.

> Внимание! В этом задании и во всех последующих заданиях на написание кода будет проверяться не только логика программы, но и стиль кода (PEP8). Для проверки стиля используется [Ruff](https://docs.astral.sh/ruff/). Нужно писать `age = 18`, а не `age=18`, не `age =18` и не `age   = 188`.

## Ответ

```python
print('дратути, мир!')
print(some_magic)
```

## Задание 13.10.9

В переменной `days` сейчас хранится количество дней. Напиши программу, которая напечатает количество секунд в этом количестве дней.

Переменную `days` не задавай — считай, что она задана в коде выше.

Например, если значение переменной `days` равно `5`, то программа должна вывести `432000`.

## Ответ

```python
print(days * 24 * 60 * 60)
```

## Задание 13.10.10

Улучши программу из предыдущего задания: пусть выводит не просто число, а строку вида `N сек.`. То есть для `days = 5` она выведет:

```
432000 сек.
```

## Ответ

```python
print(days * 24 * 60 * 60, end='')
print(' сек.')
```
