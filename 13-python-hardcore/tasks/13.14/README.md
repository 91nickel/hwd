## Задание 13.14.1

Напиши программу, которая возводит в куб переданное целое число, причём это число передаётся параметром командной строки:

```
$ python3 main.py 8
```

В данном случае программа должна напечатать `512` (это восемь в кубе).

Символом `$` тут и дальше обозначается приглашение ко вводу оболочки bash или zsh в Linux/Mac OS. Этот символ не набирается.

## Ответ

```python
import sys

number = int(sys.argv[1])
print(number ** 3)
```

## Задание 13.14.2

Напиши программу, которая суммирует три целых числа, переданных как параметры командной строки:

```
$ python3 main.py 81 12 296
```

В данном случае программа должна напечатать `389`.

## Ответ

```python
import sys

nums = list(map(int, sys.argv[1:4]))
print(sum(nums))
```

## Задание 13.14.3

Напиши программу, которая запрашивает у пользователя целое число и выводит предыдущее и следующее число:

```
$ python3 main.py
Введите число: 10
Следующее число: 11
Предыдущее число: 9
```

## Ответ

```python
curr = int(input("Введите число: "))
next = curr + 1
prev = curr - 1

print('Следующее число:', next)
print('Предыдущее число:', prev)
```

Вариант преподавателя — без промежуточных переменных:

```python
user_value = int(input("Введите число: "))
print("Следующее число:", user_value + 1)
print("Предыдущее число:", user_value - 1)
```

С промежуточными переменными и разделением блоков:

```python
user_value = int(input("Введите число: "))

next_value = user_value + 1
previous_value = user_value - 1

print("Следующее число:", next_value)
print("Предыдущее число:", previous_value)
```

С f-строкой (синтаксис впереди по программе):

```python
user_value = int(input("Введите число: "))
print(f"Следующее число: {user_value + 1}\nПредыдущее число: {user_value - 1}")
```

## Задание 13.14.4

Напиши программу, которая запрашивает у пользователя длину и ширину прямоугольника и печатает его периметр:

```
$ python3 main.py
Длина прямоугольника: 5
Ширина прямоугольника: 2
Периметр прямоугольника: 14
```

## Ответ

```python
length = int(input("Длина прямоугольника: "))
width = int(input("Ширина прямоугольника: "))
perimeter = 2 * (length + width)
print('Периметр прямоугольника:', perimeter)
```

Вариант преподавателя — точные имена переменных без сокращений:

```python
rectangle_length = int(input("Длина прямоугольника: "))
rectangle_width = int(input("Ширина прямоугольника: "))
rectangle_perimeter = 2 * (rectangle_length + rectangle_width)
print("Периметр прямоугольника:", rectangle_perimeter)
```

## Задание 13.14.5

Пользователь вводит двузначное целое число (от 10 до 99). Нужно:

- вывести десятки (первая цифра),
- вывести единицы (вторая цифра),
- вывести сумму этих двух цифр.

```
$ python3 main.py
Введите двузначное число: 47
Десятки: 4
Единицы: 7
Сумма цифр: 11
```

## Ответ

```python
num = input("Введите двузначное число: ")
first_digit = int(num[0])
second_digit = int(num[1])
print(f"Десятки: {first_digit}")
print(f"Единицы: {second_digit}")
print(f"Сумма цифр: {first_digit + second_digit}")
```

## Задание 13.14.7

Пользователь вводит два целых числа — возраст двух людей. Нужно вывести, на сколько лет один старше другого (по модулю, без отрицательных чисел).

```
$ python3 main.py
Введите возраст первого человека: 25
Введите возраст второго человека: 30
Разница в возрасте: 5
```

## Ответ

```python
first = int(input("Введите возраст первого человека: "))
second = int(input("Введите возраст второго человека: "))
print(f"Разница в возрасте: {abs(second - first)}")
```

## Задание 13.14.8

Пользователь вводит два целых числа: сколько всего страниц в книге и на сколько дней планирует растянуть чтение. Нужно вывести, сколько целых страниц нужно читать в день (без учёта остатка).

```
$ python3 main.py
Введите количество страниц: 100
Введите количество дней: 7
Страниц в день: 14
```

## Ответ

```python
pages = int(input("Введите количество страниц: "))
days = int(input("Введите количество дней: "))
print(f"Страниц в день: {int(pages / days)}")
```

## Задание 13.14.9

Перепиши программу предыдущего задания так, чтобы количество страниц и дней программа принимала из аргументов командной строки:

```
$ python3 main.py 100 7
Страниц в день: 14

$ python3 main.py 121 3
Страниц в день: 40
```

## Ответ

```python
import sys

pages = int(sys.argv[1])
days = int(sys.argv[2])
print(f"Страниц в день: {int(pages / days)}")
```
