## Задание 13.19.1

Напиши программулечку, которая будет просто печатать одну и ту же строку:

```
$ python3 main.py
Zhora O'Connor

$ python3 main.py
Zhora O'Connor
```

При этом пусть в твоей программе вообще не встречается символ одинарной кавычки `'`.

## Ответ

```python
print("Zhora O'Connor")
```

**Преподаватель:** Молодец!

> Любые символы строки можно задать по-разному. Например, строку «привет, мир!» можно напечатать так:
> ```python
> print("привет, мир!")
> ```
> Здесь каждый символ задан Unicode-эскейпом.

## Задание 13.19.2

Напиши программулечку, которая будет просто печатать одну и ту же строку:

```
$ python3 main.py
🚀🚀🚀
```

## Ответ

```python
print('🚀🚀🚀')
```

**Преподаватель:** Куча вариантов задать три ракеты!

```python
# Copy-paste символа
print("🚀🚀🚀")

# Через Unicode escape — https://symbl.cc/en/1F680-rocket-emoji/
print("\U0001F680\U0001F680\U0001F680")

# Через имя символа в Unicode
print("\N{ROCKET}\N{ROCKET}\N{ROCKET}")

# Через Unicode-коды
print(chr(0x1F680) + chr(0x1F680) + chr(0x1F680))
```

Или с умножением строки:

```python
print("🚀" * 3)
print("\U0001F680" * 3)
print("\N{ROCKET}" * 3)
print(chr(0x1F680) * 3)
```
