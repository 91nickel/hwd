## Задание 13.18.16

Напиши программулечку, которая всегда просто печатает то же, что получила на вход через `input`:

```
$ python3 main.py
Введи что-нибудь: привет
привет

$ python3 main.py
Введи что-нибудь: ромашки
ромашки
```

То есть программа печатает приглашение ко вводу (строку «Введи что-нибудь: »), пользователь вводит какую-то строку, и программа печатает эту строку.

Учти, что пользователь может ввести данные с любой кавычкой!

```
$ python3 main.py
Введи что-нибудь: операция "банан!"
операция "банан!"

$ python3 main.py
Введи что-нибудь: Д'Артаньян против Кинг Конга
Д'Артаньян против Кинг Конга
```

## Ответ

```python
msg = input('Введи что-нибудь: ')
print(msg)
```


Измени программу, чтобы работала так:
