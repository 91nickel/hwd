# Задание 13.11.1 — Привет, имя! Твой любимый цвет

Напиши программу, которая запрашивает у пользователя его имя и любимый цвет и печатает сообщение «Привет, name! Твой любимый цвет: color.», подставляя вместо name и color имя и цвет соответственно.

При запросе имени программа должна вывести на экран текст: «Как тебя зовут? », при запросе цвета: «Какой твой любимый цвет? ».

## Ответ

```python
name = input('Как тебя зовут? ')
color = input('Какой твой любимый цвет? ')
print(f"Привет, {name}! Твой любимый цвет: {color}.")
```
