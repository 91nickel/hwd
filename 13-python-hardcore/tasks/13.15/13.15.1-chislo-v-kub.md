# Задание 13.15.1 — Число в куб

Напиши программу, которая принимает на вход аргументом командной строки число (целое или не очень) и печатает это число, возведённое в куб.

```
$ python3 main.py 2
8

$ python3 main.py 2.1
9.261

$ python3 main.py -12.211
-1820.764149931
```

## Ответ

```python
import sys
from decimal import Decimal

number = Decimal(sys.argv[1])

print(number ** 3)
```
