# Задание 13.15.2 — Сумма трёх чисел

Напиши программу, которая принимает на вход аргументами командной строки три целых (или не очень) числа и выводит их сумму:

```
$ python3 main.py 10.1 12 541.0434547
563.1434547

$ python3 main.py -10.1 12 541.0434547
542.9434547
```

## Ответ

```python
import sys
from decimal import Decimal

numbersList = map(Decimal, sys.argv[1:])
print(sum(numbersList))
```
