# Задание 13.2.33 — Фанаты курса обожают Python

Все фанаты нашего курса обожают язык программирования Python.

Используя только эту информацию, выбери правильное суждение и поясни, почему именно оно — правильное:

1. не бывает фанатов нашего курса, которые не любят Python
2. все, кто любят Python, являются фанатами нашего курса
3. не бывает фанатов нашего курса, которые любят Python

## Чат с ИИ

**Студент:** Верен вариант 1, так как «Все фанаты нашего курса обожают язык программирования Python». Вариант 2 содержит ошибку. Вариант 3 прямо противоречит условию.

**Наставник:** Хорошо, но объяснение слишком общее. Исходная фраза: «Все фанаты курса обожают Python». Вариант 1: «не бывает фанатов курса, которые не любят Python».

Это одно и то же по смыслу? Если человек — фанат курса, но не любит Python — это возможно по исходному условию?

**Студент:** Не бывает фанатов нашего курса, которые не любят Python, так как «Все фанаты нашего курса обожают язык программирования Python».

## Ответ

Вариант 1. «Все фанаты обожают Python» = «не бывает фанатов без Python». Это одно и то же утверждение, перефразированное через отрицание. Вариант 2 переворачивает импликацию (ошибка конверсии). Вариант 3 — прямое противоречие.
