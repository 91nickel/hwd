## Задание 13.20.1

Напиши программулечку, которая принимает аргументом командной строки произвольное слово и печатает его в верхнем регистре с добавлением восклицательного знака:

```
$ python3 main.py привеееет
ПРИВЕЕЕЕТ!

$ python3 main.py бобёр
БОБЁР!
```

## Ответ

```python
import sys

print(sys.argv[1].upper() + '!')
```

## Задание 13.20.7

Напиши программулечку, которая принимает на вход произвольную строку и печатает True, если в ней есть символ x, иначе печатает False.

```
$ python3 main.py бобёр
False

$ python3 main.py хрен
False

$ python3 main.py xyz
True

$ python3 main.py exam
True
```

## Ответ

```python
import sys

print(sys.argv[1].find("x") != -1)
```

## Задание 13.20.10

$ python3 main.py "привет. Как оно?"
6

0

$ python3 main.py "гы"

## Задание 13.20.11

Напиши программулечку, которая принимает на вход произвольную строку, удаляет из её начала и конца пробельные символы и печатает полученную строку в кавычках:

```
$ python3 main.py "    привет!"
«привет!»

$ python3 main.py "    привет!   "
«привет!»

$ python3 main.py "    привет! Вот.  "
«привет! Вот.»
```

## Ответ

```python
import sys

print(f"«{sys.argv[1].strip()}»")
```
