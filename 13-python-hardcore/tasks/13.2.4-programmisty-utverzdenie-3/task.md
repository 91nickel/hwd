# Задание 13.2.4 — Программисты: утверждение 3

Каждый из них пишет ровно на одном из трёх языков: Python, TypeScript или Rust,
причём никакие двое не используют один и тот же язык.

Разведка доложила, что Пётр Иваныч не пишет на Rust,
а Иннокентий Мусечкин пишет на TypeScript.

**Верно ли утверждение, что Пётр Иваныч пишет на Python или на TypeScript?**

Обоснуй ответ.
