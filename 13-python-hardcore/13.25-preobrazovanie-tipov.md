# 13.25. Преобразования типов

Вскоре вы столкнётесь с задачами, где разные типы данных взаимодействуют друг с другом. Например, вы получите число от пользователя, но оно поступает в программу в виде строки. Мы начинаем использовать эту переменную, как число, но получаем ошибку:

```python
your_age = input("Твой возраст: ")
print(your_age >= 18)
# TypeError: '>=' not supported between instances of 'str' and 'int'
```

Как сделать так, чтобы всё работало? Очевидно, надо строку преобразовать в число, и тогда одно число можно будет сравнить с другим числом. То есть строку в переменной `your_age` надо преобразовать в число:

```python
your_age = input("Твой возраст: ")
your_age = int(your_age)
print(your_age >= 18)
```

И теперь всё работает!

Правда, если пользователь введёт не число, а что-то другое, программа снова упадёт с ошибкой. Но это будет темой другого урока — про то, как правильно работать с ошибками.

Для преобразования строки в нецелое число можно воспользоваться функцией `float`:

```python
distance = "120.65"
print(float(distance) > 100)
```

## Неявное преобразование типов

Давайте посмотрим на примеры неявного преобразования типов. Например, можно сложить целое и нецелое число, и Python сам преобразует типы так, чтобы операция работала.

```python
a = 5        # целое число (int)
b = 2.0      # число с плавающей точкой (float)
result = a + b
print(result)  # 7.0
print(type(result))  # float
```

Python увидел, что мы складываем `int` и `float`, и решил: «раз одно из слагаемых `float`, то и результат тоже будет `float`».

Но в других случаях Python требует, чтобы мы преобразовывали типы сами — и это важно уметь делать.

## Функции преобразования

Явное преобразование типов выполняют функции:

- `int()` — преобразует в целое число
- `float()` — в число с плавающей точкой
- `str()` — в строку
- `bool()` — в логическое значение (`True` или `False`)

## Преобразование в строку

Очень частый сценарий — надо превратить что-то в строку.

```python
age = 30
message = "Вам " + str(age) + " лет."
print(message)
```

Без `str(age)` код не сработает, как мы уже видели в уроке о форматировании строк. Хотя именно для такого сценария лучше воспользоваться форматированием, а не сложением строк, — это будет работать эффективнее.

В строку можно преобразовывать не только числа, но и логические значения, и `None`:

```python
print(str(True))
print(str(None))
```

Но когда мы передаём переменные в функцию `print`, не обязательно явно преобразовывать их в строку — `print` сделает это сам внутри себя:

```python
print(True)
print(None)

is_admin = False
name = "Пётр"
print(is_admin, name)
```

## int() обрезает, а не округляет

Что будет, если применить `int()` к `19.99`? Давайте проверим:

```python
print(int(19.99))  # 19
```

Число просто обрезается до целого. Не округляется — а именно отбрасывает дробную часть.

## Преобразование в bool

Есть функция `bool()`, которая превращает значение в `True` или `False`. Это нужно, когда хочется проверить «есть ли что-то» в переменной:

```python
name = "Анна"
print(bool(name))  # True
```

А если строка пустая:

```python
name = ""
print(bool(name))  # False
```

Вот как Python решает, что считать `False`:

- Число `0`
- Пустая строка `""`
- Пустой список `[]`
- `None`

Все остальные значения считаются `True`. Мы уже говорили об этом в уроке про функцию `bool` и преобразование в булевское значение.

## Калькулятор суммы двух чисел

Напишем калькулятор, который считает сумму двух чисел, введённых пользователем:

```python
a = input("Введите первое число: ")
b = input("Введите второе число: ")

a = int(a)
b = int(b)

print("Сумма:", a + b)
```

Если не преобразовать `a` и `b` в `int`, Python будет соединять строки:

```text
Введите первое число: 2
Введите второе число: 3
Сумма: 23  ← Ой!
```

Супер! Это уже алгоритм. Запрашиваем два числа, нам приходит тип данных строка, переводим две строки в целые числа, складываем их и выводим.

## Не всё можно преобразовать во всё

Важно помнить, что не любое значение можно преобразовать в любой тип:

```python
int("abc")    # Ошибка
float("12.3.4")  # Ошибка
```

Всегда надо проверять ошибки преобразования. Дальше мы научимся это делать.

## Не преобразовывай «на всякий случай»

Иногда начинающие разработчики стараются преобразовывать типы «на всякий случай», когда это на самом деле не нужно:

```python
print("Привет " + str("мир"))
```

Если тип правильный — не преобразовывай его повторно.
