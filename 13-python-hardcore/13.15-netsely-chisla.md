# 13.15. Нецелые числа

## float неточен

Числа с плавающей запятой (`float`) — неточные. Проверим:

```python
print(0.1 + 0.2)  # 0.30000000000000004
```

Почему? Нецелые числа в общем случае не имеют точного представления в двоичной записи — точно так же, как дробь 1/3 не имеет точной записи в десятичной: 0.3333333… и бесконечно много троек дальше. 0.3333333 это *почти* 1/3, но не равно 1/3.

Поэтому в компьютере такие числа округляются до ближайшего возможного значения, и погрешности накапливаются при вычислениях.

## decimal — точные десятичные вычисления

В Python есть встроенная библиотека для точных расчётов:

```python
from decimal import Decimal

print(Decimal('0.1') + Decimal('0.2'))  # 0.3
```

Числа хранятся как строки и обрабатываются как десятичные, а не двоичные дроби. Результат точный.

Не в каждом языке программирования есть такая встроенная библиотека. В Python — есть. Знайте и используйте!

## fractions — точные рациональные дроби

В стандартной библиотеке есть модуль `fractions` с классом `Fraction` для работы с дробями без потери точности:

```python
from fractions import Fraction

a = Fraction(3, 4)  # 3/4
b = Fraction(5, 6)  # 5/6

print(a)  # 3/4
print(b)  # 5/6

print(Fraction(1, 3) + Fraction(1, 6))  # 1/2
print(Fraction(3, 4) - Fraction(1, 2))  # 1/4
print(Fraction(2, 3) * Fraction(3, 5))  # 2/5
print(Fraction(3, 4) / Fraction(2, 5))  # 15/8
```

Все результаты остаются точными рациональными числами.
