# 13.14. 🔥ПРОГРАММУЛЬКАЕМ! Первая настоящая программа

Задача: написать программу, которая запрашивает у пользователя целое число и печатает его квадрат.

## Шаг 1 — Запрос числа у пользователя

```python
number = input("Введи целое число и я возведу его в квадрат, вжуууух: ")
```

Проверяем, что ввод работает:

```python
number = input("Введи целое число и я возведу его в квадрат, вжуууух: ")
print("ты ввёл", number)
```

## Шаг 2 — Возводим в квадрат

```python
number = input("Введи целое число и я возведу его в квадрат, вжуууух: ")
number_squared = number * number
print(number_squared)
```

Получаем ошибку:

```
TypeError: can't multiply sequence by non-int of type 'str'
```

`input()` всегда возвращает **строку** (`str`). Строку умножать на строку нельзя.

Проверяем тип:

```python
number = input("Введи целое число и я возведу его в квадрат, вжуууух: ")
print(type(number))  # <class 'str'>
```

## Шаг 3 — Приводим строку к числу

```python
number = input("Введи целое число и я возведу его в квадрат, вжуууух: ")
number = int(number)
number_squared = number * number
print(number_squared)
```

## Итоговая программа

```python
number = int(input("Введи целое число и я возведу его в квадрат, вжуууух: "))
print(number * number)
```

`int(input(...))` — вложенный вызов: результат `input()` сразу передаётся в `int()`.
