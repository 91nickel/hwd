# 13.20. Что можно делать со строками

## Неизменяемость строк

Строки в Python неизменяемые. Нельзя изменить существующую строку — можно только создать новую:

```python
song = "Сидим с % за столом, на ужин готовим полено"
new_song = song.replace("%", "бобром")
print(song)      # исходная строка не изменилась
print(new_song)  # новая строка с заменой
```

## Операции над строками

**Сложение** — создаёт новую строку из двух:

```python
name = "Алексей"
greetings = "привет, " + name
print(greetings)
```

Допустимо если происходит один раз, не в цикле.

**Повторение** — умножение строки на число:

```python
print("-" * 50)
```

**Проверка вхождения** — оператор `in` возвращает `True`/`False`:

```python
email = input()
print("@ in email:", "@" in email)
print("yandex.ru in email:", "yandex.ru" in email)
```

## Методы строк

Методы — функции, привязанные к значению конкретного типа. Вызываются через точку.

**Регистр:**

```python
message = "Ооо, приветушки!"
print(message.lower())   # ооо, приветушки!
print(message.upper())   # ООО, ПРИВЕТУШКИ!
print(message)           # исходная строка не изменилась
```

Результат можно записать в переменную с тем же именем:

```python
message = "Ооо, приветушки!"
message = message.upper()
print(message)  # ООО, ПРИВЕТУШКИ!
```

**Список всех методов** — функция `dir`:

```python
print(dir(message))
```

В VS Code методы видны и в виде подсказок при вводе `имя_переменной.`

### strip — удаление пробельных символов

```python
name = input().strip()
print("hello, " + name + "!")
```

`strip()` без аргументов удаляет из начала и конца строки:
- `" "` — пробел
- `"\t"` — табуляция
- `"\n"` — перевод строки
- `"\r"` — возврат каретки
- `"\f"` — подача страницы
- `"\v"` — вертикальная табуляция

`strip()` можно вызвать сразу после `input()`:

```python
name = input().strip()
```

С аргументом удаляет каждый из указанных символов по отдельности:

```python
some_string = "#@!text@!"
clean_string = some_string.strip("#@!123")
print(clean_string)  # text
```

### find — поиск позиции подстроки

Возвращает индекс первого вхождения. Символы нумеруются с нуля:

```python
email = input()
domain_position = email.find("@")
print(domain_position)
# hi@gmail.com → 2 (h=0, i=1, @=2)
```

## Индексы и срезы

**Обращение по индексу:**

```python
email = "hi@gmail.com"
print(email[0])   # h
print(email[1])   # i
print(email[-1])  # m  (последний)
print(email[-2])  # o
print(email[-3])  # c
```

**Срезы** `[start:stop:step]` — часть строки от `start` до `stop` (не включая `stop`):

```python
email = "hi@gmail.com"
print(email[0:12])    # hi@gmail.com
print(email[2:])      # @gmail.com  (от индекса 2 до конца)
print(email[:2])      # hi          (от начала до индекса 2)
print(email[:])       # hi@gmail.com (копия строки)

# шаг — по умолчанию 1
print(email[0:12:2])  # каждый второй символ

# отрицательный шаг — обход строки в обратную сторону
print("abcdef"[::-1])   # fedcba
print("abcdef"[3::-1])  # dcba

# совместное использование find и срезов
dog_index = email.find("@")
domain = email[dog_index + 1:12]
print(domain)  # gmail.com
```

## Длина строки

```python
email = "hi@gmail.com"
print(len(email))  # 12
```

## Приведение типов

```python
age = 25
message = "your age is " + age       # ошибка: нельзя складывать str и int
message = "your age is " + str(age)  # правильно
```

Типы можно приводить друг к другу по имени типа:

```python
age = 25
print(type(age))          # <class 'int'>

int_age   = int("25")     # строка → int
str_age   = str(25)       # число → str
float_age = float(25)     # число → float

print(type(int_age))    # <class 'int'>
print(type(str_age))    # <class 'str'>
print(type(float_age))  # <class 'float'>
```

## Проверка состава строки

```python
print("hello".islower())       # True
print("hello".isupper())       # False
print("Hello".islower())       # False
print("Hello".isupper())       # False

print("Hello".isalnum())       # True   — только буквы и цифры
print("Hello!".isalnum())      # False  — есть !
print("Hello 123".isalnum())   # False  — есть пробел
```
